# LifeOS Capture Brave Extension

Captures the current Brave tab into the local LifeOS Research Inbox.

## Install in Brave

1. Open `brave://extensions/`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select this folder:

```text
C:\Users\adars\adarsha-knowledge-base\tools\brave-lifeos-capture-extension
```

## Use

- Press `Alt+Shift+L` on any page to save it to LifeOS.
- Or click the extension icon.

The tab title + URL gets appended to:

```text
raw/research/inbox.md
```

LifeOS local server must be running:

```text
http://127.0.0.1:8787
```

If the badge says `ERR`, click the desktop LifeOS launcher first.
